# Security policy

## Supported versions

Before the first distributable release, reports concern the repository's development state. During `0.x`, only the latest minor release line receives bug and security fixes; upgrade older lines to receive fixes. Stable-major support windows will be defined before `1.0.0`. See the [release policy](docs/release-policy.md) for compatibility and upgrade expectations.

## Report a vulnerability privately

Use GitHub's [Report a vulnerability](https://github.com/jojeringnax/airwallex-php-sdk/security/advisories/new) form for this repository. Private vulnerability reporting is enabled. Include affected versions, impact and a minimal sanitized reproducer. Keep API keys, tokens, webhook secrets, customer data and live financial operations out of reports and reproduction steps.

The maintainer reviews reports privately, coordinates remediation and disclosure with the reporter, and releases fixes on the maintained line. There is no guaranteed response or remediation deadline. Keep sensitive details in the private report until coordinated disclosure. Ordinary bugs belong in public issues with sanitized diagnostics.
